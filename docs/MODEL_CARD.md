# PoultryDetect — Model Card

## Model Purpose

PoultryDetect is an academic poultry-fecal-image screening application. It classifies an uploaded image into one of four project classes:

- Coccidiosis
- Healthy
- Newcastle
- Salmonella

The application is an educational screening aid and is **not** a veterinary diagnostic system.

## Current Production Model

The production detector now uses **MobileNetV2 Transfer Learning** as its primary inference engine.

Runtime implementation:

```text
client/src/ml/transferModel.js
client/src/ml/browserModel.js
client/public/models/mobilenetv2/model.json
client/public/models/mobilenetv2/group1-shard*.bin
```

The model is loaded and executed in the browser through **TensorFlow.js**. TensorFlow.js is dynamically imported only when a scan is requested so the normal application shell does not need to download the full ML runtime on initial page load.

### Model contract

- Architecture: MobileNetV2 transfer-learning classifier
- Input: RGB image
- Input size: **128 × 128 × 3**
- Input normalization: pixel values scaled to **[0, 1]**
- Output: **4-class Softmax** probability vector
- Class order: **Coccidiosis, Healthy, Newcastle, Salmonella**
- Primary runtime: TensorFlow.js in the user's browser
- Model name shown in the UI: `MobileNetV2 Transfer Learning`
- Model version: `reference-mobilenetv2-tl-v1`

The converted TensorFlow.js model is validated in CI to ensure that its input shape is 128×128 RGB, its output layer has four units, and its final activation is Softmax.

## Upstream-Reported Performance

The upstream project reports the following results for its selected MobileNetV2 Transfer Learning model:

| Metric | Reported value |
|---|---:|
| Training accuracy | 0.98 |
| Validation accuracy | 0.90 |
| Validation loss | 0.32 |
| Model size | 9.13 MB |
| Parameters | 2,263,108 |
| Input size | 128 × 128 × 3 |
| Test accuracy | 0.93 |
| Test F1 score | 0.90 |

The upstream README contains a small internal inconsistency for validation F1: its comparison table reports **0.88**, while the following prose states **0.84**. Therefore PoultryDetect does not present either value as an independently verified production metric.

These numbers are **upstream-reported experimental results**, not a new independent evaluation performed by this repository.

## Reproducible Independent Evaluation

This repository contains an evaluator for the exact Keras checkpoint:

```text
ml/evaluation/evaluate_mobilenet.py
```

It produces:

- sample counts per class
- accuracy
- macro precision / recall / F1
- weighted precision / recall / F1
- per-class classification report
- confusion matrix JSON
- confusion matrix CSV

Example:

```bash
python ml/evaluation/evaluate_mobilenet.py \
  --model mobilenetv2.h5 \
  --split-dir organized_dataset/val \
  --output-dir ml/evaluation/results
```

Only numbers generated by this evaluator on a declared dataset split should be described as an independent project evaluation of the MobileNetV2 checkpoint.

## Lightweight Fallback Model

If the TensorFlow.js model cannot load on a device, PoultryDetect falls back to its earlier lightweight browser classifier.

Files:

```text
client/src/ml/lightweightModel.js
client/src/ml/poultryBrowserModel.json
```

The fallback uses handcrafted RGB/HSV, histogram, grayscale, gradient and spatial-block features followed by a learned multiclass linear classifier.

The fallback model was independently checked on the project validation subset and achieved approximately **87.4% accuracy**. This value belongs to the fallback classifier and must not be presented as MobileNetV2 accuracy.

## Production Output

Each scan can return and store:

```text
predictedClass
confidence
probabilities

modelVersion

```

The result screen indicates whether MobileNetV2 or the fallback engine generated the prediction.

## Known Limitations

- An image classifier cannot establish a veterinary diagnosis.
- Dataset distribution can differ substantially from real farms.
- Lighting, blur, crop, background and camera quality can change predictions.
- Similar visual patterns can appear across multiple diseases.
- The model can be overconfident on out-of-distribution or unrelated images.
- Newcastle examples are less abundant in the source data than several other classes.
- Upstream performance metrics do not automatically transfer to every deployment environment or new dataset.
- Confidence is a model probability score, not a calibrated medical probability.

## Safety Statement

Predictions must be treated as screening output only. Real disease diagnosis and treatment decisions should be made by a qualified poultry veterinarian and, where appropriate, laboratory testing.
